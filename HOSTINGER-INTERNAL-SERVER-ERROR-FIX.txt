AFTER DEPLOYMENT
1. Restart the Node.js application.
2. Open https://roumely.com/login
3. Open https://roumely.com/api/health/database

Expected healthy response:
  success: true
  message: Hostinger MySQL connection is healthy.

If health returns an errorCode:
DATABASE_AUTH_FAILED      -> database username/password is wrong
DATABASE_NOT_FOUND        -> database name is wrong
DATABASE_UNREACHABLE      -> MySQL host/connection is unavailable
DATABASE_SCHEMA_MISMATCH  -> tables/columns in phpMyAdmin do not match Prisma
DATABASE_CONFIGURATION_INVALID -> one or more environment variables are malformed

SECURITY
After confirming deployment, change the MySQL password in Hostinger because the
current password has been shared during troubleshooting. Update DATABASE_URL and
DATABASE_PASSWORD after changing it.
