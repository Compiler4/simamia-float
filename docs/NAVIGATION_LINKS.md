# Optional sidebar links

The full management pages are available immediately by URL. To add them to an existing custom sidebar, point a button/link to:

```text
/admin/staff-operations
/accountant/staff-operations
```

Suggested labels:

```text
Staff Networks & Funding
Staff Proof & Expense Review
```

The staff dashboard's existing sidebar items are already mapped to the new advanced workspace by the replacement `StaffDashboardClient.tsx`.
